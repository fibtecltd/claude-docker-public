# UML Diagram Generator
Generate PlantUML diagrams with validated syntax.
## Rules
1. Always include @startuml and @enduml tags
2. Use quoted strings for labels with spaces: A --> B : "my label"
3. Declare all participants before using them
4. Test mentally parse the diagram before outputting
5. Output to docs/diagrams/ directory
## Output format
Provide the .puml file and a brief explanation of the diagram structure.
